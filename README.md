## Functional Requirements

### Num1 - Nations (System.Array)

Must include:
1. Read nations into an array (max 250).
2. Display first 15 records via `ToString()`.
3. Sequential search and updates (Russia, China, Germany).
4. Country name equals capital filter.
5. Lowest density in Europe and Oceania.
6. Most populous in America and Europe.
7. Vowel-starting names and longest American capital.
8. `Array.Sort` by name, show first 10.
9. `Array.BinarySearch` for Chili, France, Chine, Mexique.
10. Export `Europe.txt` and `Asie.txt`.

### Num2 - Coasters (List<T>)

Must include:
1. Read coasters into `List<Coaster>`.
2. Show first 6 and last 4.
3. Update first and last records as requested.
4. Remove all "Six Flags New Orleans" entries.
5. Add Alpine Fury entry.
6. Find shortest and fastest coaster.
7. Sort by name then park.
8. Show first 6 and last 4 after sort.
9. Search Mantis/Cedar Point and Condor/The Great Escape.
10. Display speed >= 70 mph.

## Constraints Checklist

Before final submission, verify:
1. No accented characters in code identifiers or output literals.
2. Required APIs are explicitly used (`Array.IndexOf`, `Array.Sort`, `Array.BinarySearch`, `List<T>.Sort`).
3. Both projects compile.
4. Outputs are clearly split by task number.
5. `Europe.txt` and `Asie.txt` are generated by Num1.

## Development Workflow

1. Place/update datasets in `files/assets/`.
2. Implement Num1 and Num2 in separate projects.
3. Run each project and validate all 10 tasks.
4. Capture evidence/output files if required by the professor.
5. Zip each solution folder for submission.
